    <h2>What Is an HTML Paragraph?</h2>

    <p>
        Paragraphs are one of the most common elements used in HTML.
        They allow you to display blocks of text on a webpage.
    </p>

    <p>
        HTML paragraphs are created using the
        <code>&lt;p&gt;</code> element.
    </p>


    <h2>Creating a Paragraph</h2>

    <p>
        Here is a simple HTML paragraph:
    </p>

    <pre><code>&lt;p&gt;This is my first paragraph.&lt;/p&gt;</code></pre>


    <h2>Multiple Paragraphs</h2>

    <p>
        You can create as many paragraphs as your webpage needs.
    </p>

    <pre><code>&lt;p&gt;This is the first paragraph.&lt;/p&gt;

&lt;p&gt;This is the second paragraph.&lt;/p&gt;

&lt;p&gt;This is the third paragraph.&lt;/p&gt;</code></pre>


    <h2>Paragraphs and Line Breaks</h2>

    <p>
        A paragraph normally creates a separate block of text.
        If you specifically need a line break inside the same
        paragraph, you can use the <code>&lt;br&gt;</code> element.
    </p>

    <pre><code>&lt;p&gt;
    Hello World!&lt;br&gt;
    Welcome to WebMyApp.
&lt;/p&gt;</code></pre>


    <div class="alert alert-warning">

        <strong>Important:</strong>

        Do not use many <code>&lt;br&gt;</code> elements simply
        to create spacing between sections. CSS should normally
        be used for layout and spacing.

    </div>


    <h2>Example Webpage</h2>

    <pre><code>&lt;!DOCTYPE html&gt;

&lt;html lang="en"&gt;

&lt;body&gt;

    &lt;h1&gt;My Website&lt;/h1&gt;

    &lt;p&gt;
        Welcome to my website.
    &lt;/p&gt;

    &lt;p&gt;
        I am learning HTML and web development.
    &lt;/p&gt;

&lt;/body&gt;

&lt;/html&gt;</code></pre>


    <h2>Quick Exercise</h2>

    <p>
        Create a webpage containing:
    </p>

    <ol>

        <li>A main heading</li>

        <li>Three paragraphs</li>

        <li>A paragraph containing a line break</li>

    </ol>


    <div class="alert alert-success">

        <strong>Tip:</strong>

        Keep your paragraphs short and organized.
        This makes webpages easier to read, especially on mobile devices.

    </div>


    <h2>Summary</h2>

    <p>
        The <code>&lt;p&gt;</code> element is used to create
        paragraphs in HTML. You can use multiple paragraphs to
        organize written content and use <code>&lt;br&gt;</code>
        when a specific line break is required.
    </p>
