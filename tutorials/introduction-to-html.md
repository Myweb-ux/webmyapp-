    <h2>What is HTML?</h2>

    <p>
        HTML stands for <strong>HyperText Markup Language</strong>.
        It is the standard language used to create and structure
        content on webpages.
    </p>

    <p>
        Every webpage you visit uses HTML as part of its structure.
        HTML tells the browser what different pieces of content are,
        such as headings, paragraphs, images, links, lists and forms.
    </p>


    <div class="alert alert-info">

        <strong>Good to know:</strong>

        HTML is not a programming language.
        It is a markup language used to structure web content.

    </div>


    <h2>What Can HTML Create?</h2>

    <p>
        HTML allows you to create the basic structure of a webpage.
    </p>

    <ul>

        <li>Headings</li>

        <li>Paragraphs</li>

        <li>Images</li>

        <li>Links</li>

        <li>Lists</li>

        <li>Buttons</li>

        <li>Forms</li>

        <li>Tables</li>

    </ul>


    <h2>Your First HTML Document</h2>

    <p>
        A basic HTML document looks like this:
    </p>


    <pre><code>&lt;!DOCTYPE html&gt;
&lt;html lang="en"&gt;

&lt;head&gt;

    &lt;meta charset="UTF-8"&gt;

    &lt;meta name="viewport"
          content="width=device-width, initial-scale=1.0"&gt;

    &lt;title&gt;My First Webpage&lt;/title&gt;

&lt;/head&gt;

&lt;body&gt;

    &lt;h1&gt;Hello World!&lt;/h1&gt;

    &lt;p&gt;Welcome to my first webpage.&lt;/p&gt;

&lt;/body&gt;

&lt;/html&gt;</code></pre>


    <h2>Understanding the Structure</h2>

    <h3>The DOCTYPE Declaration</h3>

    <p>
        The <code>&lt;!DOCTYPE html&gt;</code> declaration tells
        the browser that the document uses HTML5.
    </p>


    <h3>The HTML Element</h3>

    <p>
        The <code>&lt;html&gt;</code> element contains the entire
        HTML document.
    </p>


    <h3>The Head Element</h3>

    <p>
        The <code>&lt;head&gt;</code> element contains information
        about the webpage that is not normally displayed directly
        on the page.
    </p>


    <h3>The Body Element</h3>

    <p>
        The <code>&lt;body&gt;</code> element contains the visible
        content of the webpage.
    </p>


    <h2>Your First Heading</h2>

    <p>
        The <code>&lt;h1&gt;</code> element creates a main heading.
    </p>


    <pre><code>&lt;h1&gt;My First Website&lt;/h1&gt;</code></pre>


    <h2>Your First Paragraph</h2>

    <p>
        The <code>&lt;p&gt;</code> element creates a paragraph.
    </p>


    <pre><code>&lt;p&gt;Welcome to my first website!&lt;/p&gt;</code></pre>
