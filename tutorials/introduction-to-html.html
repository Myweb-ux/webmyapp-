HTML Beginner

Introduction to HTML

Learn what HTML is, why it exists, and how to create your first webpage.

8 min read

What is HTML?

HTML stands for HyperText Markup Language. It is the standard language used to create and structure content on webpages.

HTML tells the browser what different parts of a webpage are, such as headings, paragraphs, images, links, lists and forms.

Good to know: HTML is not a programming language. It is a markup language used to structure web content.

What Can HTML Create?

HTML allows you to create the basic structure of a webpage.

  • Headings
  • Paragraphs
  • Images
  • Links
  • Lists
  • Buttons
  • Forms
  • Tables

Your First HTML Document

A basic HTML document looks like this: 

<!DOCTYPE html>
<html lang="en">

<head>

    <meta charset="UTF-8">

    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">

    <title>My First Webpage</title>

</head>

<body>

    <h1>Hello World!</h1>

    <p>Welcome to my first webpage.</p>

</body>

</html>

Understanding the Structure

The DOCTYPE Declaration

The <!DOCTYPE html> declaration tells the browser that the document uses HTML5.

The HTML Element

The <html> element contains the entire HTML document.

The Head Element

The <head> element contains information about the webpage that is not normally displayed directly on the page.

The Body Element

The <body> element contains the visible content of the webpage.

Your First Heading

The <h1> element creates a main heading. 

<h1>My First Website</h1>

Your First Paragraph

The <p> element creates a paragraph. 

<p>Welcome to my first website!</p>
Tip: Keep practicing by creating small HTML pages. The more HTML you write, the easier the structure becomes.

Quick Exercise

Create an HTML page containing:

  1. One main heading
  2. Two paragraphs
  3. A second heading
Challenge: Try creating the page yourself before looking at the answer.

Summary

HTML provides the structure of a webpage. In this lesson, you learned what HTML is, how an HTML document is structured, and how to create basic headings and paragraphs.
